## Smart Filter Interactions

1. **Motorhome selected** (Class A/B/C) → hide towing filters, show mileage/fuel type
2. **Towable selected** (TT/5th/Toy Hauler) → show towing filters, hide mileage/fuel type
3. **Boondocking Ready toggled** → highlight generator, solar, fresh water in features section so users understand what qualifies

## UI Behavior

- **Real-time filtering** — debounced 300ms, no "Apply" button on desktop
- **Active filter count** — badge on "More Filters" button
- **Clear All Filters** — button when any active
- **Removable chips** — active filters shown above results (e.g., "Travel Trailer x")
- **Result count** — "Showing 47 of 312 RVs" updates live
- **URL params** — filters reflect in URL for sharing/bookmarking
- **localStorage** — last-used filters persist between visits
- **Mobile** — full-screen slide-up drawer with "Apply" button and result count preview

## Outfitter Integration

Bottom of filter panel shows a CTA card:
> "Not sure what you need?"

> **[Start Matching]** → navigates to `/outfitter` with current filters pre-loaded as buyer profile

This is the bridge between self-serve browsing and AI-guided matching.

## API

```
GET /api/listings?rv_type=travel_trailer,fifth_wheel&max_price=50000&condition=new&min_sleeps=6&boondocking_ready=true&sort=price_asc&page=1&limit=24
```

- Parameterized queries (no string interpolation) to prevent SQL injection
- Paginated results with total count
- Returns enriched listing objects with all new fields
