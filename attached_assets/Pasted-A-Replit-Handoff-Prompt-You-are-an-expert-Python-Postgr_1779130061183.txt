A# Replit Handoff Prompt

You are an expert Python/Postgres web scraping engineer. I am uploading a Washington State RV dealer inventory scraper package. Please integrate it into my Replit app and make it production-ready.

## Context

The previous pipeline was undercounting inventory:

- It effectively capped/skipped large dealer runs, especially dealers with more than 200 listings.
- It silently dropped records in import/sync because of mismatched fields like `type` vs `rv_type`, missing reason-level skip reporting, and global VIN dedupe.
- It did not implement the required business dedupe rule.
- Reolit/display was showing fewer records than scraped because records were lost between scrape output and DB import.

The included files are:

- `DIAGNOSIS.md`: root-cause analysis.
- `requirements.txt`: Python dependencies.
- `wa-dealers.json`: Washington dealer list.
- `rv_inventory_scraper/`: new Python scraper/sync package.

## Required Behavior

1. Scrape every reachable inventory page for each dealer, with no hard listing cap.
2. Exclude any listing with zero photos.
3. Required listing fields:
   - photos, minimum 1
   - description when available
   - specs: year, manufacturer/brand, model, floorplan, length, slides, plus other available specs
   - price
4. Deduplicate only these categories:
   - Class C
   - Fifth Wheels
   - Travel Trailers
5. For those categories only, within a single dealer, keep one listing per:
   - `year + manufacturer + brand + model + floorplan`
6. Do not deduplicate any other category. Class A, Class B, toy haulers, popup campers, truck campers, etc. must retain every unit.
7. Full sync behavior:
   - add new listings
   - update changed listings
   - flag sold listings if the DB has sold columns, otherwise remove missing active listings
8. Track price changes for all listings.
9. Queue notifications for customers opted in to price-change alerts.
   - Notification payload must include previous price, new price, and reduction amount.
10. Schedule the sync to run daily at 3:00 AM using APScheduler unless the Replit app already has a better scheduler pattern.

## Integration Steps

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Set environment variables:

```bash
DATABASE_URL=postgresql://...
DEALERS_FILE=wa-dealers.json
SCRAPER_OUTPUT=output/wa-rv-inventory.json
SCRAPER_TIMEZONE=America/Los_Angeles
```

3. Run a one-time scrape/sync:

```bash
python -m rv_inventory_scraper.cli --dealers wa-dealers.json --output output/wa-rv-inventory.json
```

4. Run the scheduler:

```bash
python -m rv_inventory_scraper.scheduler
```
