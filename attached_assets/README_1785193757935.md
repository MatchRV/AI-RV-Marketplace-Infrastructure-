# MatchRV Inventory Import

6,882 RV listings across WA / OR / ID from 26 dealers, plus 22,335 photo URLs.

## Files
| file | rows | notes |
|---|---|---|
| `dealers.csv` | 26 | `is_existing=true` marks dealers already in your Supabase (IDs preserved) |
| `listings.csv` | 6,882 | `listing_id` is a CSV-local key; the DB assigns its own |
| `listing_photos.csv` | 22,335 | one row per image, ordered by `position` |
| `schema.sql` | – | Postgres DDL, safe to re-run |
| `load.py` | – | idempotent loader |

## Run
```bash
pip install psycopg2-binary
DATABASE_URL="postgres://user:pass@host:5432/db" python load.py
```

## Dealer IDs
`Fife RV Center` reuses your existing `dealer_id = 2`. IDs 1, 5, 7, 8 (Tacoma RV,
RV Country, Baydos, Discount RV) are left untouched — those dealers were not scraped.
New dealers start at ID 9, so nothing collides.

## Re-running
`listings` has a unique index on `(dealer_id, external_id)`. Re-running updates price,
condition, location, photo count and `last_seen_at` instead of duplicating. To detect
sold units, mark rows whose `last_seen_at` is older than your latest run:

```sql
UPDATE listings SET is_active = false
WHERE last_seen_at < now() - interval '2 days';
```

## Known gaps
- **Price**: 6,236 of 6,882 have one. The rest show "Call for price" on the source site.
- **Photos**: 1,145 listings have them (Overfuel, Automanager, WooCommerce dealers).
  DealerSpike galleries need a per-unit detail fetch that is currently rate-limited.
- **VIN**: only Overfuel dealers publish it on listing pages.
- `state` is derived per unit from its own listing location, not the dealer HQ —
  several dealers here are multi-state chains.
