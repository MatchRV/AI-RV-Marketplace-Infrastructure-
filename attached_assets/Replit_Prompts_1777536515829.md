Send each candidate's specs (sleeps, length, weight, generator, bunkhouse, fresh_water_capacity, features, description, etc.) along with the full buyer profile. Claude returns JSON with the top 3 listing IDs, a `whyMatch` description (2-3 personalized sentences referencing the buyer's specific needs), and a `matchScore` (0-100). If the re-ranking call fails, fall back to returning the first 3 SQL results.

4. Create a `getMatchedListings(profile)` function that runs: buildListingFilters → SQL query (LIMIT 15) → rerankWithAI → return top 3 with whyMatch and matchScore attached.
