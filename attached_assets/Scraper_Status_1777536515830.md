# Scraper Status

## Overview

The scraper (`lotlink-scraper/`) crawls Washington state RV dealer websites, extracts listing data, and normalizes it into a consistent 68-field schema.

## How It Works

```
wa-rv-dealers.json (71 dealers)
        |
        v
   Scraper runs per dealer
        |  Visits inventory pages
        |  Extracts listing details
        |  Normalizes to schema
        v
   JSON files (one per dealer domain)
        |  e.g., fifervcenter-com.json
        |  Keyed by VIN / stock number / URL hash
        v
   Diff Engine (store/diff.js)
        |  Compares current vs previous scrape
        |  Detects: new, removed, price change, back-on-market
        v
   Inventory updates ready for DB
```

## Output Format

Each dealer file contains records keyed by identifier:
```json
{
  "VIN_OR_STOCK_NUMBER": {
    "dealer_name": "Fife RV Center",
    "year": 2025,
    "make": "Forest River",
    "model": "Rockwood",
    "rv_type": "Travel Trailer",
    "price": 35990,
    "sleeps": 6,
    "length": 28,
    ...
    "_first_seen": "2026-04-01",
    "_last_seen": "2026-04-26",
    "_price_history": [
      {"date": "2026-04-01", "price": 37990},
      {"date": "2026-04-15", "price": 35990}
    ]
  }
}
```

## Diff Detection

The diff engine tracks:
- **New listings** — appeared since last scrape
- **Removed listings** — no longer on dealer site (sold or pulled)
- **Price changes** — price went up or down
- **Back on market** — previously removed listing reappeared

## Data Quality

Each listing includes confidence metadata:
- `extraction_confidence`: high | medium | low
- `extraction_notes`: array of issues (e.g., "price not found, estimated from title")
- `field_sources`: maps each field to the HTML element/API it came from

## Dealer Coverage

- **Total dealers:** 71 (Washington state)
- **Source file:** `wa-rv-dealers.json`
- **Primary market:** Fife/Tacoma area

## Known Gaps

- Some dealers use JavaScript-rendered inventory pages — scraper may miss dynamically loaded listings
- Price accuracy varies — some dealers show "Call for Price" which results in null
- RV type normalization isn't perfect — some dealers use non-standard type names
- Sleeps count sometimes missing — not all dealers list this prominently
